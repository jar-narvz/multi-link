States every option needs

Colours are the TUI's theme roles: Claude orange, Codex blue, green for done and amber for running. The pane is drawn with Claude Code's own elements (Box, Text), so the final look follows the surface: terminal, desktop or VS Code. Width and refresh rate are open questions for the plan.
